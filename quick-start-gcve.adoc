= Guia rápido para migrar para o Google Cloud VMware Engine usando o assistente de migração de cargas de trabalho da VMware
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Comece a usar o assistente de migração da VMware para migrar sua infraestrutura atual para o Google Cloud VMware Engine usando o Google Cloud NetApp Volumes como datastores NFS externos.

Antes de começar, você deve ter uma compreensão do https://docs.netapp.com/us-en/workload-setup-admin/permissions-reference.html["permissões para NetApp Workload Factory"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"]Efetue login no Workload Factory
[role="quick-margin-para"]
Você precisará https://docs.netapp.com/us-en/workload-setup-admin/sign-up-saas.html["crie uma conta no Workload Factory"^] e faça login usando um dos https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiências de console"^] .

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"]Adicionar credenciais e permissões
[role="quick-margin-para"]
Escolha o https://docs.netapp.com/us-en/workload-setup-admin/permissions-reference.html["políticas de permissão"] Para atender às suas necessidades.

[role="quick-margin-para"]
Se optar por não conceder permissões, você pode começar a usar o Workload Factory para VMware para copiar exemplos de código parcialmente concluídos.

[role="quick-margin-para"]
Se optar por conceder permissões, você precisará https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["Adicionar credenciais a uma conta manualmente"] fornecer a uma conta de serviço do GCP as permissões necessárias para visualizar e gerenciar recursos do Google Cloud NetApp Volumes, configuração de VPC e conectividade do datastore do Google Cloud VMware Engine.

[role="quick-margin-para"]
https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["Saiba como adicionar credenciais e permissões"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"]Carregar dados de inventário de VM
[role="quick-margin-para"]
Você pode usar o centro de planejamento para carregar detalhes de inventário sobre seu ambiente de VM atual.  Use o script do coletor de dados, o RVTools ou o NetApp Data Infrastructure Insights para capturar sua configuração atual de VM e carregar os dados no centro de planejamento.

[role="quick-margin-para"]
link:upload-vm-inventory.html["Aprenda a fazer upload de dados de inventário de VM"^] .

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatro"] Crie um plano de implantação usando o consultor de migração da VMware
[role="quick-margin-para"]
Inicie o VMware migration advisor e configure o ambiente de máquina virtual que deseja criar na infraestrutura do Google Cloud VMware Engine usando o Google Cloud NetApp Volumes como datastores NFS externos.

[role="quick-margin-para"]
link:launch-migration-advisor-gcve.html["Saiba como usar o consultor de migração da VMware para criar um plano de implantação"].
